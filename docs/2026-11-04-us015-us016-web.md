# 2026-11-04 — Lát US-015 / US-016 trên web

## Context

WBS 3.1.1–3.1.2 (bản Vĩ): ngày 4/11 Hiếu làm US-015 cấp tài khoản BQT và US-016 đăng nhập. Charter ghi Java desktop + MySQL. Nhóm chọn **web** cho implement.

## Problem

Làm cả app trong một ngày lệch Sprint 1 (04–08/11). Java desktop lệch quyết định web. Database `bluemoon` local thuộc đồ án nhóm 7 khóa trước — không tái sử dụng.

## Solution

App mỏng: bảng `users` trên `bluemoon_se09`, seed một ADMIN, màn cấp tài khoản, màn đăng nhập, màn chính, placeholder căn hộ/nhân khẩu/thu phí/báo cáo bị chặn khi chưa login. Căn hộ (US-001) và đổi mật khẩu (US-017) không làm hôm nay.
